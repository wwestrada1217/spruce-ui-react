# P1.0-11 data-display parity matrix

Angular baseline: `../spruce-ng/projects/spruce-ui` data-display (and core `SpBadge`), plus the matching pages under `../spruce-ng/projects/docs/src/app/pages/components`.

React implementation rule: Angular inputs become typed props, outputs become callbacks, projected templates become render props, and Angular service/signal/directive mechanics become React hooks, controlled state, or native DOM behavior.

## Verification focus

- Interaction tests cover controlled state, callbacks, keyboard movement, drag guards, recursive/indeterminate selection, virtualization, service-style terminal logging, and accessibility roles.
- Each component uses existing Spruce chrome/i18n infrastructure and CSS custom properties; component-specific literal colors remain only for inherently branded credit-card/network artwork or caller-supplied colors.
- Documentation pages expose the Angular behavior through idiomatic React examples and API tables, including light/dark and RTL notes where the behavior is observable.
