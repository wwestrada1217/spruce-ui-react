# P1.0-02 Forms and lookup parity matrix

Baseline read before implementation: `spruce-ng/projects/spruce-ui/forms/src/lib/` and the matching component pages under `spruce-ng/projects/docs/src/app/pages/components/`. React counterparts inspected under `src/components/` and `docs/src/pages/components/`.

## Shared field contract

| Angular surface | React contract | Behavior and accessibility |
| --- | --- | --- |
| `disabled`, `readonly`, `hidden` | controlled props, merged with `FormFieldContext` | Native disabled/read-only semantics; hidden controls render no DOM; callbacks are suppressed when unavailable. |
| `invalid`, `errors`, `required`, `hint` | `invalid`, `errors`, `required`, `hint`/field context | Error IDs and `aria-invalid`/`aria-describedby`; required state is exposed to the native control. |
| `ariaLabel`, `ariaLabelledby`, `ariaDescribedby` | `ariaLabel`, `ariaLabelledBy`, `ariaDescribedBy` | Explicit labels win over generated descriptions; visible labels remain associated with controls. |
| Angular `valueChange`/`checkedChange`/selection outputs | controlled `value`/`checked` plus `onChange` | React callbacks receive the next value, never a DOM event; selected-object outputs use `onSelectedItem`. |
| Angular templates and `ng-template` contexts | `renderOption`, `renderEmpty`, `renderRow` | Render callbacks receive item, normalized option, selected, and highlighted state. |
| Angular DI, signals, directives, and `Observable` data sources | React context, hooks, callbacks, and `IReadableDataSource`/URL sources | No Angular-only mechanism is copied; asynchronous reads are cancellable by normal React ownership and failures become empty/loading states. |

## Intentional React mappings

- Angular selected-object outputs map to `onSelectedItem`; the primary controlled callback always receives the next scalar/array value.
- Angular `IDataSource`/paging maps to `IReadableDataSource`, array sources, or URL sources. `readLookupPage` normalizes local filtering, remote responses, page metadata, and search fields.
- Angular option/row templates map to render callbacks rather than structural directives.
- Modal constraining remains a positioning boundary concern owned by the React host; placement, outside-click, and scroll-dismiss behavior are exposed without Angular overlay injection.
