# P1.0-01 form foundation parity matrix

Angular baseline: `../spruce-ng/projects/spruce-ui/forms/src/lib/field.ts`, `form-layout.ts`, and `input-group.ts`, plus their component documentation pages. React implementation: `src/components/field`, `src/components/form-layout`, `src/components/input-group`, and the shared Input/Textarea contract.

| Surface | Angular property/behavior | React API/behavior | Events/callbacks | Accessibility and direction |
| --- | --- | --- | --- | --- |
| `Field` | `label`, `labelFor`, required marker, helper/error/success feedback | `label`, `labelFor`, `required`, `helperText`, `errorText`, `successText`, `errors`, `invalid` | Controlled child callbacks are preserved; no Angular signal form binding | Native `<label>` association, generated feedback IDs, `role="alert"` errors, `aria-invalid`, `aria-required`, `aria-readonly`, `aria-describedby`, localized required title, logical RTL CSS |
| `Field` layout | Vertical/inline, custom label width, stack-on-mobile | `layout`, `labelWidth`, `stackOnMobile`; inherited `FormLayout` context | No event; layout is declarative | `dir` follows `useI18n()` and inline layout uses logical properties |
| `Field` state contract | Angular form state includes `readonly`, `hidden`, `invalid`, `errors`, `required` | `FormControlContractProps`, `FormValidationError`, `FormFieldContext`; `Field` passes state to a single child and provides context to custom controls | Controlled values and callbacks remain the source of truth | Hidden fields are removed from layout; state is reflected on the control where the child supports the contract |
| `FormLayout` | Directive modes vertical/horizontal/compact/grid; columns, gap, label width, responsive | `FormLayout` with `layout`, `columns`, `gap`, `labelWidth`, `responsive`, `as="form"` or default `div` | `onSubmit`/`onReset` when `as="form"` | Context replaces Angular DI; helper classes support semantic headings, rows, full-span content, dividers, and action areas |
| `FormLayout` helpers | `.sp-form__section-title`, `.sp-form__row`, `--2/--3/--4`, `.sp-form__full`, divider/actions | Same class contract in `FormLayout.css` | N/A | Grid and responsive behavior use logical, tokenized CSS and work in both themes |
| `InputGroup` | Size/layout, disabled/invalid, role/label, addon chrome toggles | `InputGroup` with `size`, `layout`, `disabled`, `invalid`, `ariaLabel`, `ariaLabelledBy`, `role`, `hideAddonBackground`, `hideAddonSeparator` | Child `InputGroupButton.onClick` receives the native mouse event; native input `onChange` remains available | Group role/name and invalid state, focus-visible buttons, logical addon separators, RTL direction |
| `InputGroupInput` | Native `input`/`textarea` directive styles flexible control | Controlled/native props via `InputGroupInput`, `as="textarea"` | Native DOM callbacks | Disabled and invalid state inherit from group; semantic input/textarea retained |
| `InputGroupAddon` | Prefix/suffix text and icons | `InputGroupAddon` with `children` | N/A | Decorative content remains outside the input’s accessible name unless the group label names it |
| `InputGroupActions` / `Spacer` | Composition action row and flexible spacer | `InputGroupActions`, `InputGroupSpacer` | N/A | Layout-only elements are non-interactive; spacer is `aria-hidden` |
| `InputGroupButton` | Type, disabled, aria label, default/ghost/soft, icon-only, `pressed` output | `InputGroupButton` with controlled `disabled`, `type`, `ariaLabel`, `variant`, `iconOnly`, `onClick` | Native `onClick` callback | Icon-only buttons require `ariaLabel`; native button keyboard behavior and visible focus retained |
| Input/Textarea integration | Floating label, hidden/readonly/invalid/errors/required, native ARIA, outline/filled/chrome | Added `hidden`, `readOnly`, `invalid`, `errors`, `label`, `floatingLabel`, `variant`, chrome/radius/border, ARIA props; Field context is consumed | Existing controlled `value`/`onChange`; focus/blur callbacks added | Error/hint IDs from `Field` are wired to the real control, floating labels remain labels, tokenized light/dark states |

Angular-only mechanisms intentionally not copied: signal models, `FormValueControl`, DI tokens, content-projection directives, and `ng-content`. React context, children, and controlled props provide the same user-visible contract.
