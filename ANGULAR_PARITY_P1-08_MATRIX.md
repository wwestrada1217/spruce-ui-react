# P1.0-08 shell and sidebar parity matrix

This matrix records the Angular baseline read from `../spruce-ng/projects/spruce-ui/sidebar` and the related docs pages `sidebar-page`, `app-header-page`, `company-switcher-page`, `popover-tooltip-page`, and `app-shell-block`. Angular inputs, outputs, signals, services, and content projection map to controlled React props, callbacks, context hooks, and `children`/render props.

## Cross-cutting acceptance checklist

- Public user-changeable state has controlled props/callbacks plus convenient uncontrolled defaults.
- User-facing and assistive labels resolve through `useI18n()` unless explicitly overridden.
- Native buttons and form controls carry keyboard behavior; resize handles support arrows/Home/End.
- CSS uses Spruce semantic, spacing, motion, and logical-direction tokens, with reduced-motion fallbacks.
- Existing React APIs remain source-compatible where practical, including `SidebarMenuGroup.items`, `AppHeader.actions`, and render-prop shell slots.
- Focused tests cover controlled state, keyboard resizing, mobile dismissal, popover selection, RTL, and axe checks.
