## Public property and event matrix

| Angular API / behavior | React API | Result |
| --- | --- | --- |
| `src` image URL/data URL, default `''` | `src?: string` | Supported; source changes reload the editor and clear the edit history. |
| `alt`, default `Editable image` | `alt?: string` | Supported as the accessible source description. |
| `ariaLabel`, default localized `imageEditor` | `ariaLabel?: string` | Supported on the keyboard-operable workspace. |
| `format` (`image/png`, `image/jpeg`, `image/webp`) | `format?: ImageEditorOutputFormat` | Supported for crop/export MIME type and filename extension. |
| `initialQuality`, default `0.92`, clamped to `0.1..1` | `initialQuality?: number` | Supported for initial/reset export quality. |
| `changed` output | `onChange?: (change) => void`, `onChanged?` alias | Supported after edits, keyboard nudges, and export. |
| `cropped` output | `onCrop?: (change) => void`, `onCropped?` alias | Supported before the crop result is loaded back into the editor. |
| Angular internal tool signal | `tool?: ImageEditorTool`, `onToolChange?` | Controlled or uncontrolled selection/text/draw/shape tools. |
| Angular internal aspect signal | `aspect?: ImageEditorAspect`, `onAspectChange?` | Free, square, `4:3`, `16:9`, `3:2`, and `2:3` constraints. |
| Angular internal zoom signal | `zoom?: number`, `onZoomChange?` | Controlled or uncontrolled `25%..300%` zoom. |
| Angular internal quality signal | `quality?: number`, `onQualityChange?` | Controlled or uncontrolled `10%..100%` quality. |
| Angular internal adjustment signals | `adjustments?: ImageEditorAdjustments`, `onAdjustmentsChange?` | Controlled or uncontrolled brightness, contrast, hue, saturation, exposure, opacity, and blur. |
| Angular internal transform signals | `rotation?`, `flipX?`, `flipY?` plus callbacks | Rotate left and flip horizontally/vertically. |
| Angular internal selection signal | `selection?: ImageEditorSelection \| null`, `onSelectionChange?` | Controlled or uncontrolled crop selection in displayed workspace coordinates. |
| Angular internal selection shape signal | `selectionShape?`, `onSelectionShapeChange?` | Rectangle/circle crop mode. |
| Angular internal annotations signal | `annotations?`, `onAnnotationsChange?` | Controlled or uncontrolled text, path, rectangle, ellipse, line, and arrow annotations. |
| Angular hard-coded annotation color | `annotationColor?: string` | New annotations use a token-backed default and allow consumer customization. |
| Upload toolbar | `onSourceChange?: (source, file) => void` | Local image upload creates a temporary object URL and resets image editing state. |

## Behavior, keyboard, and accessibility matrix

| Angular behavior | React implementation | Accessibility / theme result |
| --- | --- | --- |
| Drag on image creates a selection | Pointer events on the `role="application"` workspace | Workspace is focusable and labeled; selection is bounded to the transformed image. |
| Drag selection to move it | Pointer capture on the viewport | Works with touch/pointer input and does not lose the drag outside the selection. |
| Drag eight resize handles | Eight focusable, labeled handle buttons | Handle labels identify the resize direction; visible token focus rings are provided. |
| Fixed-ratio selection | Aspect toolbar button and native select | Native select remains keyboard operable and uses localized labels. |
| Circle selection | Toggle button with `aria-pressed` | Circle mode forces a square ratio as in Angular. |
| Text annotation at center / clicked point | Add button or text tool + workspace click | Text, rotate, and scale controls are named buttons. |
| Freehand draw | Pointer-captured path annotation | Drawing is rendered to the visible canvas and exported output. |
| Rectangle, ellipse, line, arrow | Pointer-created SVG overlays and canvas output | SVG is decorative (`aria-hidden`); the workspace carries the accessible interaction label. |
| Zoom slider and zoom buttons | Native range plus labeled icon buttons | Range is keyboard operable; percentage is announced with `aria-live`. |
| Rotate left / flip horizontal / flip vertical | Labeled command buttons | Uses Spruce `Button`, token focus, and logical layout. |
| Brightness / contrast / hue / saturation / exposure / opacity / blur | Expandable labeled adjustment group with native ranges | `aria-expanded`/`aria-controls` connect the toggle and panel; all labels use `useI18n`. |
| Quality slider | Native labeled range | Value is visible and keyboard operable. |
| Reset | Labeled action button, disabled until an image is ready | Uses native disabled semantics. |
| Undo/redo history | 60-state history with toolbar buttons and `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z`, `Ctrl/Cmd+Y` | Disabled state and button labels expose availability. |
| Arrow-key selection nudging | Arrow = 1px; Shift + Arrow = 10px | Prevents page scroll while a selection is active and emits `onChange`. |
| Crop | Renders selected region, emits callback, loads crop in place | Circle clipping is preserved for output. |
| Export/download | Renders selection or full image and downloads `image-edit.<ext>` | Output callback receives data URL, Blob, selection, shape, adjustments, format, and quality. |
| Checkerboard image workspace | Token-backed surface and border styles | Works with light/dark themes and inherits document RTL direction. |
| Angular i18n service | `useI18n()` and existing locale provider | Toolbar, empty state, status text, controls, and adjustment labels are localized; custom labels remain possible through `SpruceI18nProvider`. |
