# P1.0-10 Angular editor parity matrix

This matrix records the Angular sources and documentation reviewed for P1.0-10 and the controlled React surface implemented in this package. Angular dependency injection, signals, and directives are represented as explicit React props, callbacks, provider functions, refs, or local state.

## Verification scope

Focused tests cover controlled value flow, keyboard editing and completion, diff mode/navigation, mention interaction, markdown validation/count, block persistence/undo, and the in-place type/action matrix. The existing routes and sidebar entries for all six editor pages were inspected and retained in `docs/src/App.tsx` and `docs/src/components/nav.ts`.
