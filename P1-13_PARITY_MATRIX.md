# P1-13 Angular parity matrix

This matrix records the applicable public API and behavior from the Angular source packages named by `ANGULAR_PARITY_AUDIT.md`, and the React API used for the port. Angular-only dependency injection, signals, and directives are represented as React composition, refs, hooks, and controlled callbacks.

| Surface | Angular properties / inputs | React properties / callbacks | Behavior and events | Accessibility, i18n, RTL, themes |
| --- | --- | --- | --- | --- |
| Grid | `fluid`; `cols`; `gap`; `align`; `span`; `offset` | `Container fluid`; `Row cols/gap/align`; `Col span/offset`; native HTML attributes and `style` | Same token-based container, CSS grid, offsets, custom column counts, and common layout composition | Native labels/roles pass through; logical padding; tokens work in light/dark themes |
| Layout manager | Items with `x/y/w/h`, min/max constraints, static/draggable/resizable/deletable; `cols`, `rowHeight`, `gap`, `margin`, `compactType`, `preventCollision`, `locked`, breakpoints | Controlled `items` + `onItemsChange`; `onLayoutChange`, drag/resize start/end, delete, breakpoint callbacks; `renderItem`; `LayoutDragHandle`; imperative `save/restore/deleteItem` ref | Grid snapping, collision push/rejection, compaction, responsive column selection, resize handles, delete confirmation, keyboard movement/resizing | `role=group`, roledescription, tab focus, arrows/Shift/Alt/Delete, i18n aria label, logical CSS, tokenized states, reduced-motion-friendly transitions |
| Dock manager / auto-hide | Tree nodes (`leaf`, `tab`, `document`, `split`), floats, auto-hide entries; panel title/icon/closeable/zones/header/badge; persistence and bottom tabs | Controlled `layout`, `onLayoutChange`, `storageKey`, `thinSplitters`, `dense`, `tabsAtBottom`; `DockPanel`, `DockPanelTools`, `AutoHideStrip`; ref methods for import/export/reset/activate | Split/tab/document rendering, tab activation/close, splitter keyboard/pointer resizing, HTML5 docking, floating panels, JSON persistence, auto-hide peek/restore | Tablist/tab semantics, separators, Escape/outside-click peek close, i18n labels, logical edge strips, design tokens and dark-theme variables |
| Masonry | `columns`; `minColumnWidth`; `gap`; projected `SpMasonryItem` registration and responsive measurement | `<Masonry>` with `<MasonryItem>` children and `columns/minColumnWidth/gap` | ResizeObserver layout, shortest-column placement, automatic columns, item readiness/index/data attributes, reduced-motion mode | DOM order remains logical; no direction-specific assumptions; tokenized gap and motion-safe transforms |
| Drag/drop | Group, accepts, disabled flags, handle, axis, effectAllowed/dropEffect, data type/text, live sort, preview tilt; started/entered/moved/left/dropped/ended outputs | Generic `<DragDrop>` with the same properties and `onDragStarted/onDragEntered/onDragMoved/onDragLeft/onDropped/onDragEnded` callbacks | Pointer activation threshold, compatible target registry, before/inside/after zones, live sorting, clone preview, cancel restoration | `aria-disabled`, `aria-grabbed`, keyboard-safe focus, touch-action, focus-visible styling, logical horizontal borders, theme tokens |
| Fullscreen | `active` controlled/uncontrolled, `mode` overlay/native/class, z-index, background, Escape, active-change output | `<Fullscreen>` with `active`, `onActiveChange`, `mode`, `zIndex`, `overlayBackground`, `exitOnEscape`; `FullscreenHandle` ref | Overlay fixed viewport, native Fullscreen API synchronization, class-only state, Escape exit, enter/exit/toggle methods | Escape behavior is explicit; fullscreen background/z-index are style props backed by tokens; works in both color schemes |
| Hide on scroll | Scroller, disabled, threshold, idle reveal; hidden-change output | `useHideOnScroll` and `<HideOnScroll>` with `scroller`, `disabled`, `threshold`, `idleReveal`, `onHiddenChange` | Nearest scroll parent or window, RAF batching, top reveal, direction threshold, idle reveal, focus reveal, scrollbar-drag protection | Focus-in reveals; vertical logical transform works in RTL; reduced-motion media query and tokenized transition |

## Intentionally React-specific

The directive host element becomes an explicit component or hook ref. Angular content templates become `renderItem`/children render props, Angular outputs become callback props, and Angular public methods become imperative handles only where a command is inherently imperative (fullscreen, layout persistence, docking persistence). No Angular service injection, signal, or directive syntax is exposed.
