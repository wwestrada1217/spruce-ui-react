# P1.0-07 Angular parity matrix

This matrix records the Angular baseline used for P1.0-07 and the React API used to express the same behavior without Angular-only dependency injection, signals, or directives. Angular source and documentation were read from `../spruce-ng/projects/spruce-ui` before the React counterparts were changed.

## Cross-cutting acceptance checklist

- All public state that maps to Angular models has a controlled React prop and callback, with a default prop for convenient uncontrolled use.
- Labels that are user-facing or assistive use `useI18n()`; no new hard-coded English is required for component behavior.
- Keyboard interactions use native buttons where possible, explicit roving focus where needed, and logical direction-aware placement/scrolling.
- CSS uses Spruce tokens, logical properties, dark-theme-safe semantic colors, and reduced-motion fallbacks.
- Existing React data-driven APIs remain source-compatible where practical; compound APIs are additive.
- Unit tests cover controlled state, keyboard behavior, accessibility attributes, and overflow/truncation behavior.
