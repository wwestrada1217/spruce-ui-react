# P1.0-12 parity matrix

Angular source baseline: `../spruce-ng/projects/spruce-ui/data-display/src/lib` and
`../spruce-ng/projects/spruce-ui/components/table`.

| Surface | Properties / public types | Behavior | Events / React callbacks | Accessibility, i18n, RTL, themes |
| --- | --- | --- | --- | --- |
| Table | Generic `rows`, `columns`, column `key/header/sortable/value`; `density`, `pagination`, `pageSize`, `vertical`, `ariaLabel`, `borders`, `headerBackground`, `striped`, `hover`, `emptyMessage`, `cellAlign`; controlled `sort` and `page` | Stable asc/desc sorting, optional paging, empty row, vertical first-record summary, formatted values, density/alignment variants | `onSortChange`, `onPageChange` | Native table semantics, `aria-sort`, labelled sort buttons, logical text alignment, localized table/empty defaults, tokenized light/dark styling |
| ComposeBar | `size`, `shape`, `children`, `leading`, `trailing`, `className`, `style` | Three-slot shell for input/editor, focus state follows descendants, projected utility classes | Child controls own their value and actions | Focus ring, keyboard-native projected controls, logical slot order, tokenized surface/radius/density/motion styling |
| CommentThread | `comments`, required `currentUser`, `mentionItems`, `reactionPalette`, `allowReplies`, localized/overrideable placeholders and empty text; optional controlled drafts/reply target | One reply level, mention insertion/highlighting, relative timestamps, reaction palette, delete affordance for current user, scrollable list with pinned composer | `onCommentSubmit`, `onReactionToggle`, `onCommentDelete`, optional draft/reply callbacks | Native buttons, pressed/expanded/menu state, escaped mention rendering, Intl relative time, localized labels, logical reply indentation and dark/RTL-safe tokens |
| PropertyPanel | `properties`, controlled `values/query/mode/collapsedGroups`, visibility/footer/search labels; property editors `text/number/boolean/select/color/readonly/dialog/compound`, children, mixed/default/modified metadata | Search, categorized or alphabetical ordering, collapsible groups, inline editor updates, compound expansion, dialog hand-off, focused-property footer | `onValuesChange`, `onQueryChange`, `onModeChange`, `onCollapsedGroupsChange`, `onPropertyChange`, `onFocusedPropertyChange`, `onOpenDialog` | Table-like row semantics, radio/checkbox/expanded state, labels/tooltips, localized defaults, logical borders/padding, tokenized states for both themes |
| PdfViewer | `src`, `title`, `height`, toolbar/open/download toggles, action labels, `downloadFileName`, empty/loading labels | Native iframe preview, loading lifecycle, empty state, new-tab and download actions | `onLoaded`, `onFailed` | Busy/status labels, iframe title, keyboard-native links, safe direct URL usage, responsive toolbar, tokenized light/dark frame |
| TextDiff | `oldText`, `newText`, `granularity`, `appearance`, deletion/insertion styles, `showSummary`, `ariaLabel` | LCS word/character diff, equal/delete/insert segments, meaningful insertion/deletion counts | No Angular output; pure presentational controlled inputs | Escaped text, labelled comparison, polite live summary, pre-wrap/overflow-safe layout, logical and tokenized styles |
| PlanCards | `plans` and `SpPlanCardFeatureGroup`/`SpPlanCardModel`, `loading`, `skeletonCount`, `recommendedLabel` | Responsive plan grid, recommended ribbon, icon/badge/tagline/capacity/groups, CTA, reduced-motion skeletons | `onPlanSelect` with the complete plan model | Heading hierarchy, list semantics, loading is decorative/status-safe, localized recommended label, tokenized responsive light/dark styling |
| Entitlements / gate | `EntitlementFeature`, snapshot/provider inputs, endpoint/fetcher; `FeatureGate` feature/fallback/loading; `FeatureLocked` copy/actions | Reactive `has` and `limitFor`, explicit async `load`, soft hide/fallback gate, locked upgrade panel; no Angular DI/directive/route guard | `load()` promise; consumer callbacks for upgrade/actions | Fail-closed gate while unresolved, semantic note/heading, localized defaults, logical/tokenized locked state, usable in RTL/dark themes |

The React API intentionally uses controlled props and callbacks where Angular used signal inputs/models/outputs. Angular dependency injection, structural directives, signals, and router guards are represented by React context, hooks, render gating, and an explicit async loader instead of being copied literally.
